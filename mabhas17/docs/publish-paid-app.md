# مسیر ارزان — انتشار به‌عنوان اپ پولیِ یک‌بار خرید در کافه‌بازار

این مسیرِ انتخاب‌شده است: **اپ پولی، خرید یک‌باره، بدون بک‌اند.**

نه سرور، نه پنل پیامک، نه ثبت‌نام، نه اشتراک، نه پرداخت درون‌برنامه‌ای.
**هزینهٔ ماهانهٔ نگهداری: صفر.** تنها هزینه‌ها یک‌بارهٔ حساب توسعه‌دهندهٔ بازار است.

> نقشهٔ گران‌تر (ورود پیامکی + اشتراک ماهانه/سالانه) در
> `plan-bazaar-subscription.md` دست‌نخورده مانده است. اگر بعداً خواستی، از همان
> ادامه می‌دهیم — این مسیر هیچ دری را نمی‌بندد.

## ⛔ دو چیز که همین حالا باید حل شوند

### ۱) مخزن عمومی است — سورس اپ در دسترس همه است

`Morashidian8/Tictactoestevie` **public** است. یعنی هر کسی می‌تواند
`mabhas17/web/index.html` را باز کند و کلِ اپی که می‌خواهی بفروشی را رایگان
بردارد. تا وقتی این‌طور است، فروش معنا ندارد.

دو راه:

- **مخزن را private کن** — ساده‌ترین. Settings → General → پایین صفحه →
  Change repository visibility. ولی آن‌وقت GitHub Pages (اپ‌های HSE، منهول،
  پلی‌بات، و صفحهٔ حریم خصوصی) روی حساب رایگان از دسترس خارج می‌شود.
- **یا فقط اپ مبحث ۱۷ را به یک مخزن private جدا ببر** — مثل کاری که با
  `polybot-private` کردی. بقیهٔ پروژه‌ها عمومی می‌مانند و Pages سالم می‌ماند.
  **این را توصیه می‌کنم.**

> ⚠️ فقط private کردن کافی نیست: تاریخچهٔ گیت عمومی بوده و ممکن است جایی
> کش/فورک شده باشد. برای اپی به این اندازه، این ریسکِ قابل‌قبولی است — ولی
> بدان که «پاک شدن از اینترنت» تضمین‌شده نیست.

### ۲) ورکفلو، APK را در ریلیزِ عمومی می‌گذاشت — برداشته شد ✅

مرحلهٔ «Publish APK to a Release» از `.github/workflows/mabhas17-android.yml`
حذف شد. حالا خروجی فقط artifact خصوصیِ همان اجراست. اگر برنداشته بودیم، اپِ
پولی از صفحهٔ ریلیزِ گیت‌هاب رایگان دانلود می‌شد.

## ۱) کلید امضا (keystore) — یک‌بار، و برای همیشه

بدون این، APK قابل انتشار نداری. **گمش کنی دیگر هرگز نمی‌توانی برای این اپ
آپدیت بدهی** — بازار آپدیتِ امضاشده با کلید دیگر را قبول نمی‌کند.

روی هر کامپیوتری که جاوا دارد (یا در Android Studio: Build → Generate Signed
Bundle / APK → Create new):

```bash
keytool -genkeypair -v \
  -keystore mabhas17.jks \
  -alias mabhas17 \
  -keyalg RSA -keysize 2048 -validity 10000 \
  -storetype PKCS12
```

بعد سه چیز را جای امن نگه دار (و یک نسخهٔ پشتیبان جدا):
فایل `mabhas17.jks` · رمز keystore · رمز کلید.

> کامپیوتر نداری؟ بگو تا گزینه‌ها را برایت بررسی کنم. این کلید نباید از مسیر
> ناامن رد شود — بدترین کار این است که در یک چت یا مخزن عمومی قرار بگیرد.

---

## ۲) ساخت APK امضاشده، بدون کامپیوتر

چهار Secret را در **Settings → Secrets and variables → Actions** بساز:

| نام Secret | مقدار |
| --- | --- |
| `MABHAS17_KEYSTORE_BASE64` | خروجی `base64 -w0 mabhas17.jks` |
| `MABHAS17_KEYSTORE_PASSWORD` | رمز keystore |
| `MABHAS17_KEY_ALIAS` | `mabhas17` |
| `MABHAS17_KEY_PASSWORD` | رمز کلید |

بعد: **Actions → Build Mabhas17 signed release → Run workflow**.

خروجی، artifact ای به نام `mabhas17-release-apk` است که فقط خودت می‌بینی
(۷ روز نگهداری). ورکفلو قبل از تحویل، امضای APK را با `apksigner` بررسی می‌کند
و اگر امضا نشده باشد عمداً شکست می‌خورد — تا هیچ‌وقت اشتباهی APK امضانشده به
بازار نفرستی.

> ورکفلو اگر کپیِ داخل `assets/pwa/` با `mabhas17/web/` یکی نباشد هم می‌شکند.
> این عمدی است: تنها راهِ ناهمگام‌شدنِ نسخهٔ وب و اندروید همین بود.

## ۳) صفحهٔ حریم خصوصی

بازار برای انتشار یک URL سیاست حریم خصوصی می‌خواهد. آماده است:
`mabhas17/privacy.html` و با هر انتشار Pages اینجا سرو می‌شود:

```
https://morashidian8.github.io/Tictactoestevie/mabhas17/
```

**قبل از ارسال، یک جای خالی را پر کن:** ایمیل پشتیبانی، در بخش «تماس».

نوشتنش آسان بود چون اپ واقعاً هیچ داده‌ای جمع نمی‌کند — حتی مجوز اینترنت
ندارد. همین موضوع بازبینیِ بازار را هم ساده می‌کند؛ آن را خراب نکن.

> اگر مخزن را private کردی، Pages از دسترس خارج می‌شود و باید این صفحه را
> جای دیگری بگذاری. یک راه رایگان: یک مخزن عمومیِ کوچک فقط برای همین صفحه.

## ۵) قیمت‌گذاری

با احتساب کارمزد بازار (⚠️ تاریخاً حدود ۳۰٪ — عدد روز را از پنل خودت بگیر)،
برای یک ابزار تخصصیِ یک‌بار خرید:

- قیمت را برای **مهندس ناظر و مجریِ گاز** ببند، نه برای کاربر عمومی. مخاطبِ
  این اپ کم است ولی حاضر به پرداخت است؛ ارزان‌فروشی اینجا فروش را زیاد نمی‌کند.
- شروع با یک قیمت، و بالا بردنش بعداً، از پایین آوردن آسان‌تر است.
- تخفیف‌های دوره‌ای بازار ابزار خوبی برای دیده‌شدن است.
