# محاسبات گاز — مبحث ۱۷ (اپلیکیشن اندروید)

اپ اندروید برای محاسبات لوله‌کشی گاز طبیعی بر اساس **مبحث ۱۷ مقررات ملی ساختمان (ویرایش پنجم)**.

## معماری
این اپ، نسخه‌ی کامل و آفلاینِ اپلیکیشن (همان PWA) را در یک **WebView** اجرا می‌کند.
- همه‌ی محاسبات و داده‌ها در `app/src/main/assets/pwa/index.html` قرار دارند (کاملاً آفلاین، بدون نیاز به اینترنت).
- نسخه‌ی وب و اندروید **همیشه یکی** هستند؛ برای به‌روزرسانی کافی است فایل‌های داخل `assets/pwa/` را جایگزین کنید.
- خروجی، یک **APK واقعی** برای نصب و انتشار است.

## بخش‌های اپ (۱۷ بخش)
سایز لوله · تأمین هوا · افت فشار/طول معادل · دودکش (مستقل/مشترک/لوله رابط) · کنتور و رگولاتور · آزمایش نشتی و مقاومت · مبدل واحد · فواصل لوله گاز · جداول مرجع · مصالح · ضوابط اجرا · چک‌لیست بازرسی · تعاریف · فشار متوسط (بخش دوم) · پیوست‌ها.

---

## ۱) باز کردن و اجرا در Android Studio
1. Android Studio (نسخه Hedgehog یا جدیدتر) → **Open** → پوشه‌ی `mabhas17/android` را انتخاب کنید.
2. صبر کنید Gradle Sync کامل شود (وابستگی‌ها خودکار دانلود می‌شوند).
3. دکمه **Run ▶** را بزنید تا روی شبیه‌ساز یا گوشی متصل اجرا شود.

## ۲) ساخت APK برای ارسال به دیگران (نصب دستی / Sideload)
این روش برای فرستادن به چند نفر (واتساپ، تلگرام، ...) مناسب است:
1. در Android Studio: منوی **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
2. پس از پایان، روی **locate** بزنید؛ فایل اینجاست:
   `app/build/outputs/apk/debug/app-debug.apk`
3. همین فایل `.apk` را برای دیگران بفرستید. آن‌ها باید در گوشی خود گزینه‌ی
   **«نصب از منابع ناشناس / Install unknown apps»** را برای آن برنامه (مثلاً واتساپ/فایل‌منیجر) فعال کنند و روی فایل بزنند.

> نکته: نسخه‌ی debug برای تست و ارسال داخلی خوب است. برای انتشار رسمی، نسخه‌ی **امضاشده (release)** بسازید (بخش بعد).

## ۳) ساخت نسخه‌ی امضاشده برای پلی‌استور (AAB) یا انتشار رسمی
گوگل‌پلی فرمت **AAB** می‌خواهد:
1. **Build → Generate Signed Bundle / APK**.
2. گزینه‌ی **Android App Bundle (AAB)** را انتخاب کنید.
3. یک **Keystore** بسازید (Create new...) و رمز و اطلاعاتش را در جای امن نگه دارید
   (این کلید برای همه‌ی به‌روزرسانی‌های بعدی لازم است — گمش نکنید!).
4. **Build variant: release** → Finish.
5. خروجی: `app/release/app-release.aab` — همین فایل را در
   [Google Play Console](https://play.google.com/console) آپلود کنید.

### نکات انتشار در پلی‌استور
- ثبت‌نام یک‌بار در Play Console هزینه‌ی ۲۵ دلاری دارد.
- به آیکون، تصاویر اسکرین‌شات، توضیحات و سیاست حریم خصوصی نیاز دارید.
- چون اپ آفلاین است و داده‌ای جمع نمی‌کند، سیاست حریم خصوصی ساده خواهد بود.
- برای فروشگاه‌های داخلی (مثل بازار/مایکت) معمولاً همان فایل **APK امضاشده** کافی است:
  در مرحله‌ی ۲ بالا به‌جای AAB گزینه‌ی **APK** و **release** را انتخاب کنید.

## ۴) تغییر نام، آیکون و نسخه
- **نام برنامه:** `app/src/main/res/values/strings.xml` → `app_name`
- **آیکون:** `app/src/main/res/drawable/ic_launcher.xml` (یا از Image Asset Studio آیکون جدید بسازید)
- **شناسه و نسخه:** در `app/build.gradle.kts` → `applicationId`، `versionCode`، `versionName`
  (برای هر آپدیت در پلی‌استور باید `versionCode` را یک واحد زیاد کنید.)

## ۵) به‌روزرسانی محتوای محاسبات
کافی است فایل‌های داخل `app/src/main/assets/pwa/` را با نسخه‌ی جدید جایگزین کنید
(همان فایل‌های پوشه‌ی `mabhas17/web/`). نیازی به تغییر کد کاتلین نیست.

## پیش‌نیازها
- Android Studio + Android SDK (Platform 34)
- JDK 17+
- حداقل اندروید نسخه ۷ (API 24)

> سلب مسئولیت: داده‌ها از مبحث ۱۷ ویرایش پنجم استخراج شده‌اند؛ مسئولیت کنترل نهایی و استفاده در پروژه‌ی واقعی بر عهده‌ی مهندس مسئول است.
