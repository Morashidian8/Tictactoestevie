# راهنمای تولید محتوای درس

هر درس یک فایل TypeScript در `src/content/lessons/` است. **نام فایل باید دقیقاً
برابر شناسهٔ درس باشد**: `g<پایه>-l<شمارهٔ درس>.ts` — مثلاً `g9-l1.ts`.
فایل به‌محض ساخته‌شدن، خودکار در اپ ثبت می‌شود (`registry.ts` با `import.meta.glob`).

## اسکلت فایل

```ts
import type { Lesson } from '../types'

const lesson: Lesson = {
  id: 'g9-l1',          // = نام فایل
  grade: 9,
  number: 1,            // ۰ برای «ستایش»
  unit: 'زیبایی آفرینش',
  title: '…',
  subtitle: '…',
  by: 'سعدی',
  minutes: 25,
  free: true,           // اختیاری

  teach: { intro, goals, author, body, glossary, devices, grammar, literary, summary },
  practice: [ … ],      // ۸ تا ۱۲ سؤال
  exam: { minutes, passScore, questions: [ … ] },  // ۶ تا ۱۰ سؤال
  help: { faq, mistakes, tips },
}

export default lesson
```

## بخش تدریس

- `intro` — سه تا پنج جمله. بگو درس دربارهٔ چیست و کلیدواژه‌اش کدام است.
- `goals` — سه تا پنج هدف، همه با فعل دوم‌شخص: «…را بگویی»، «…را نشان دهی».
- `author` — زندگی‌نامهٔ کوتاه؛ سال‌ها، شهر، آثار.
- `body` — آرایه‌ای از بلوک‌ها:
  - `{ kind: 'heading', text }` — عنوان میانی
  - `{ kind: 'verse', verses: [{ n, a, b, meaning, note? }] }` — شعر
  - `{ kind: 'prose', paragraphs: [{ n, text, meaning, note? }] }` — نثر
  - `{ kind: 'note', title, text }` — کادر نکته (برای «پیام کلی درس»)
- `glossary` — **هر واژهٔ سختی که دانش‌آموز ممکن است نداند.** سخاوتمند باش؛
  فلش‌کارت‌های لایتنر خودکار از همین ساخته می‌شوند.
- `devices` — هر آرایه با یک `example` که **عیناً از متن درس** باشد.
- `grammar` — نکته‌های دستوری، متناسب با سطح پایه. برای دهم تا دوازدهم
  «قلمرو زبانی» و برای هفتم تا نهم «دانش زبانی» کتاب را پوشش بده.
- `summary` — پنج تا هفت خط. این همان چیزی است که شب امتحان خوانده می‌شود؛
  باید به‌تنهایی کافی باشد.

## سؤال‌ها

شش نوع سؤال پشتیبانی می‌شود:

| نوع | میدان‌ها | نکته |
|---|---|---|
| `mcq` | `choices`, `answer` (اندیس از ۰) | چهار گزینه |
| `truefalse` | `answer: boolean` | |
| `fill` | `accept: string[]` | اولی پاسخ اصلی؛ مقایسه با نرمال‌سازی فارسی |
| `match` | `left[]`, `right[]` | **هم‌اندیس‌ها جفتِ درست‌اند**؛ ستون چپ خودکار به‌هم می‌ریزد |
| `order` | `items[]` | به ترتیبِ درست بنویس |
| `short` | `sample`, `keywords[]` | نمره‌دهی خودکار بر پایهٔ کلیدواژه |

هر سؤال `topic` می‌خواهد؛ همین است که «نقاط ضعف» را در کارنامه می‌سازد:

```
'واژگان' | 'معنی و مفهوم' | 'آرایه‌های ادبی' | 'دستور زبان'
| 'املا و نگارش' | 'دانش ادبی' | 'درک مطلب'
```

`explain` اجباری است — دانش‌آموز باید بفهمد **چرا**، نه فقط اینکه غلط بوده.

`points` فقط در آزمون معنا دارد (پیش‌فرض ۱). مجموعِ نمره‌ها به ۱۰۰٪ و سپس به
نمرهٔ ۲۰ تبدیل می‌شود.

## بخش رفع اشکال

- `faq` — سؤال‌هایی که واقعاً در کلاس پرسیده می‌شود، نه سؤال‌های تشریفاتی.
- `mistakes` — الگوی `wrong / right / why`. مؤثرترین بخش درس برای امتحان.
- `tips` — ترفندِ به‌خاطرسپاری، نه تکرارِ خلاصه.

## قواعد نگارشی

- نیم‌فاصله را رعایت کن: «می‌گوید»، «آرایه‌های ادبی».
- ارقام را فارسی ننویس؛ کد خودش تبدیل می‌کند (`fa()` در `lib/format.ts`).
- برای کسرهٔ اضافه در شعر، وقتی معنی را عوض می‌کند، اعراب بگذار: «خداوندِ دل».
- گیومهٔ فارسی «…» به‌کار ببر.
