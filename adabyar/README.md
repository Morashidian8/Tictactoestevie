# ادب‌یار — AdabYar

> اپلیکیشن جامع آموزش ادبیات فارسی، پایهٔ هفتم تا دوازدهم

ادب‌یار برای این ساخته شده که دانش‌آموز برای درس‌خواندن و امتحان‌دادن، به کتاب و
جزوه و کلاس نیازی نداشته باشد. هر درس چهار بخش دارد:

| بخش | چه چیزی دارد |
|---|---|
| **تدریس** | درآمد، زندگی‌نامهٔ شاعر، متن کامل درس با معنیِ بیت‌به‌بیت، واژه‌نامه، آرایه‌های ادبی، دانش زبانی (دستور)، دانش ادبی، خلاصهٔ شب امتحان |
| **تمرین** | تمرین گام‌به‌گام با بازخورد فوری و پاسخ تشریحی — شش نوع سؤال |
| **آزمون** | آزمون زمان‌دار با کارنامه، نمرهٔ ۲۰، شناسایی نقاط ضعف و پاسخ‌نامهٔ تشریحی |
| **رفع اشکال** | سؤال‌های پرتکرار، اشتباه‌های رایج، ترفندهای به‌خاطرسپاری |

## امکانات

- 📚 **شش پایه** — فهرست کامل درس‌های فارسی هفتم تا دوازدهم
- 🎯 **آزمون‌ساز** — ساخت آزمون دلخواه از چند درس و چند مبحث (مثل آزمون نوبت اول/دوم)
- 🃏 **جعبهٔ لایتنر** — فلش‌کارت خودکار از واژه‌نامه و آرایه‌های هر درس با مرور فاصله‌دار
- 📈 **کارنامه و نقاط ضعف** — نمودار هفتگی، میانگین آزمون‌ها، ریزموضوع‌هایی که باید بیشتر کار شود
- 🔥 **گیمیفیکیشن** — امتیاز، سطح، عنوان (نوآموز تا خداوندگار سخن)، روزهای پیاپی، نشان
- 🌙 **حالت شب/روز**، اندازهٔ متن قابل تنظیم، **خط نستعلیق** برای شعرها
- 🔊 **خوانش متن** با موتور گفتار مرورگر
- 📴 **کاملاً آفلاین** — PWA با نصب روی صفحهٔ اصلی
- 💾 **بدون حساب کاربری** — همهٔ داده‌ها روی دستگاه خودِ دانش‌آموز، با خروجی پشتیبان

## اجرا

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # خروجی در dist/
npm run preview
```

## ساختار

```
src/
  content/
    types.ts        مدل دادهٔ محتوا (درس، سؤال، آزمون، رفع اشکال)
    curriculum.ts   فهرست همهٔ درس‌های شش پایه
    registry.ts     ثبت خودکار درس‌ها + بارگذاری تنبل
    lessons/*.ts    محتوای کامل هر درس (نام فایل = شناسهٔ درس)
  components/       اجزای رابط کاربری و موتور سؤال
  pages/            صفحه‌ها
  store/            وضعیت (تنظیمات، پیشرفت، لایتنر، اشتراک)
  lib/              ابزارها (فارسی‌سازی عدد، نرمال‌سازی متن، گفتار)
```

افزودن یک درس تازه = ساختن یک فایل در `src/content/lessons/`.
راهنمای کامل: [`docs/CONTENT-GUIDE.md`](docs/CONTENT-GUIDE.md)

## وضعیت محتوا

| پایه | درس‌های آماده |
|---|---|
| هشتم | شیر حق |
| نهم | ستایش، آفرینش همه تنبیه خداوند دل است |
| دوازدهم | شکر نعمت، مست و هُشیار، نی‌نامه |

بقیهٔ درس‌ها در فهرست هستند و با برچسب «به‌زودی» نمایش داده می‌شوند.
برای پرکردنشان [`docs/CONTENT-GUIDE.md`](docs/CONTENT-GUIDE.md) و
[`docs/ROADMAP.md`](docs/ROADMAP.md) را بخوانید.
