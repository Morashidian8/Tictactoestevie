# نسخه آفلاین PWA — بازدید ایمنی و آتش‌نشانی ساختمان

نسخه **کاملاً آفلاین** و **بدون سرور** اپلیکیشن بازدید HSE. تمام منطق، ذخیره‌سازی و
تولید خروجی‌های Word و Excel **داخل خود مرورگر** انجام می‌شود. روی گوشی **نصب** می‌شود
و پس از نصب، حتی بدون اینترنت کار می‌کند.

## امکانات (یکسان با نسخه Flask)
1. **ویزارد تک‌آیتمی** — ۱۸۹ آیتم در ۱۸ حوزه، هر بار یک ردیف.
2. وضعیت (✅ مطلوب / ⚠️ نیاز به بهبود / ❌ نامطلوب / **N/A کاربرد ندارد**)، توضیح و آپلود عکس
   (📷 دوربین یا 🖼 انتخاب از پوشه/گالری).
3. **خروجی Word تصویری** — عکس‌ها با شرح آیتم و توضیح ناظر زیر هر عکس، برای موارد دارای ایراد.
4. **خروجی Excel** — ردیف‌های پاسخ‌داده‌شده با **حذف موارد «کاربرد ندارد»** و محاسبه درصد ایمنی.

عکس‌ها در **IndexedDB** و پاسخ‌ها در **localStorage** روی همان دستگاه ذخیره می‌شوند
(ادامه بازدید نیمه‌کاره ممکن است). هیچ داده‌ای به سرور ارسال نمی‌شود.

## تفاوت با نسخه Flask
| | Flask (`hse_inspection/`) | PWA (`hse_pwa/`) |
|---|---|---|
| سرور / نصب Python | لازم | لازم نیست |
| تولید Word/Excel | سمت سرور (python-docx, openpyxl) | داخل مرورگر (docx.js, ExcelJS) |
| آفلاین | فقط روی دستگاه سرور | کاملاً آفلاین پس از نصب |
| نصب روی موبایل | اتصال به IP سیستم | نصب مستقل روی صفحه گوشی |

## اجرا و تست محلی
چون PWA باید از طریق http سرو شود (نه `file://`):
```bash
cd hse_pwa
python3 -m http.server 8000
# مرورگر: http://localhost:8000
```

## انتشار برای نصب روی گوشی (GitHub Pages)
این مخزن **دو اپ** را روی یک سایت Pages میزبانی می‌کند تا با هم تداخل نکنند:
- اپ تحلیل کندل بیت‌کوین در **ریشه**: `https://<user>.github.io/Tictactoestevie/`
- اپ ایمنی HSE در زیرمسیر **`/hse/`**: `https://<user>.github.io/Tictactoestevie/hse/`

هر دو توسط یک workflow واحد (`.github/workflows/pwa.yml`) منتشر می‌شوند: ابتدا اپ
بیت‌کوین در `site/` ساخته و سپس پوشه `hse_pwa` در `site/hse/` کپی می‌شود.

برای انتشار/به‌روزرسانی:
1. تغییرات را در `main` ادغام کنید.
2. در GitHub: **Settings → Pages → Source: GitHub Actions** (یک‌بار).
3. workflow **«Build & Deploy PWA»** را از تب Actions اجرا کنید (Run workflow).
4. آدرس `/hse/` را روی گوشی باز کنید → **«افزودن به صفحه اصلی»**. پس از نصب آفلاین کار می‌کند.

## ساختار
- `index.html` , `styles.css` , `app.js` — رابط و منطق ویزارد + تولید خروجی‌ها
- `checklist_data.json` — داده استخراج‌شده از اکسل اصلی
- `manifest.webmanifest` , `sw.js` — نصب‌پذیری و کش آفلاین
- `vendor/` — کتابخانه‌های مرورگری ExcelJS، docx.js، FileSaver
- `icons/` — آیکن‌های اپ
