# ربات پیش‌بینی رنگ کندل بیت‌کوین (BTC Next-Candle Color Predictor)

رباتی تلگرامی که مثل یک **اسکلپر** عمل می‌کند: حدود **۱ دقیقه قبل** از باز شدن
هر کندل **۵ دقیقه‌ای بیت‌کوین** (BTCUSDT از بایننس)، با اجرای یک مجموعه تحلیل
تکنیکال حدس می‌زند آن کندل **سبز 🟢** یا **قرمز 🔴** بسته خواهد شد و فقط
**ساعت کندل + رنگ** را برایت می‌فرستد. مثال پیام:

```
۱۲:۰۵🟢
```

> ⚠️ **توجه صادقانه:** رنگ کندل بعدی عملاً نزدیک به «شیر یا خط» است و هیچ
> تحلیلی نمی‌تواند آن را با قطعیت پیش‌بینی کند. این ربات یک **حدس منظم و
> بازتولیدپذیر** بر پایه تحلیل تکنیکال می‌زند، نه تضمین سود.

## دستورات تلگرام

| دستور | کار |
|-------|-----|
| `/start` | شروع پیش‌بینی مداوم (۱ دقیقه قبل از هر کندل ۵ دقیقه‌ای) |
| `/stop` | توقف پیش‌بینی |
| `/status` | نمایش وضعیت (فعال/متوقف) و جزئیات تحلیل آخرین پیش‌بینی |
| `/predict` | یک پیش‌بینی فوری برای کندل بعدی همین حالا |

پس از `/start` ربات تا وقتی `/stop` بزنی به‌صورت مداوم ۲۴ ساعته کار می‌کند.

## منطق تحلیل (اسکلپر)

موتور تحلیل در `predictor.py` چند سیگنال کلاسیک را با وزن ترکیب می‌کند و یک
امتیاز نهایی بین ۱- (کاملاً قرمز) تا ۱+ (کاملاً سبز) می‌سازد:

- روند EMA سریع/کند (EMA9 در برابر EMA21)
- شیب EMA سریع
- هیستوگرام MACD و گسترش/جمع‌شدن آن
- مومنتوم RSI و بازگشت از نواحی اشباع (overbought/oversold)
- نرخ تغییر کوتاه‌مدت (ROC)
- بدنه آخرین کندل (ادامه‌ی حرکت)
- فاصله قیمت از EMA50
- تأیید حجم معاملات

علامت امتیاز نهایی = رنگ پیش‌بینی‌شده، و اندازه‌ی آن = میزان اطمینان.

## راه‌اندازی

۱. یک ربات بساز: به [@BotFather](https://t.me/BotFather) پیام بده، `/newbot`
   را بزن و توکن را بگیر.

۲. فایل محیطی را آماده کن:

```bash
cp .env.example .env
# سپس TELEGRAM_TOKEN را در فایل .env قرار بده
```

۳. نصب وابستگی‌ها:

```bash
pip install -r requirements.txt
```

۴. اجرا:

```bash
python bot.py
```

۵. در تلگرام به ربات `/start` بفرست. ربات به‌طور خودکار `chat_id` تو را ذخیره
   می‌کند و پیش‌بینی‌ها را به همان‌جا می‌فرستد. هر وقت خواستی `/stop` بزن.

## تنظیمات (متغیرهای محیطی)

| متغیر | پیش‌فرض | توضیح |
|-------|---------|-------|
| `TELEGRAM_TOKEN` | — | توکن ربات (الزامی) |
| `TELEGRAM_CHAT_ID` | خالی | در صورت خالی بودن با `/start` خودکار پر می‌شود |
| `PRODUCT` | `BTCUSDT` | نماد معاملاتی بایننس |
| `INTERVAL` | `5m` | تایم‌فریم کندل |
| `GRANULARITY` | `300` | اندازه کندل به ثانیه (۳۰۰ = ۵ دقیقه) |
| `KLINES_LIMIT` | `200` | تعداد کندل برای محاسبه اندیکاتورها |
| `LEAD_SECONDS` | `60` | چند ثانیه قبل از باز شدن کندل پیش‌بینی ارسال شود |
| `TICK_SECONDS` | `3` | فاصله بررسی ساعت توسط زمان‌بند |
| `DISPLAY_TZ` | `Asia/Tehran` | منطقه زمانی ساعت نمایش‌داده‌شده در پیام |
| `PERSIAN_DIGITS` | `1` | `1` = ارقام فارسی (۱۲:۰۵)، `0` = لاتین (12:05) |

## اجرای دائمی ۲۴ ساعته

برای اجرای پایدار از `systemd`، `pm2`، `docker` یا یک سرور ابری استفاده کن.
نمونه ساده با `nohup`:

```bash
nohup python bot.py > bot.log 2>&1 &
```

## منبع داده

داده‌ها از API عمومی بایننس گرفته می‌شوند (بدون نیاز به کلید API)؛ چند هاست به
ترتیب امتحان می‌شوند تا اگر یکی مسدود بود (مثلاً HTTP 451/403) به هاست بعدی
برود:

```
https://data-api.binance.vision/api/v3/klines?symbol=BTCUSDT&interval=5m
```
