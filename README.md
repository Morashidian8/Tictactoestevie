# ربات هشدار تناوب کندل بیت‌کوین (Bitcoin Candle Alternation Alert Bot)

رباتی برای تلگرام که **۲۴ ساعته** کندل‌های **۵ دقیقه‌ای بیت‌کوین** را از
**بایننس (Binance)** بررسی می‌کند و هرگاه جهت کندل‌ها (سبز/قرمز یا مثبت/منفی)
چند بار پشت سر هم **متناوب** شود، روی کندلی که این تناوب را کامل می‌کند برای شما
یک **هشدار** می‌فرستد.

## منطق هشدار

- هر کندل بسته‌شده «سبز» (close > open) یا «قرمز» (close < open) در نظر گرفته می‌شود.
- اگر جهت کندل‌ها به صورت سبز، قرمز، سبز، قرمز، ... ادامه پیدا کند، طول این
  تناوب شمارش می‌شود.
- وقتی تعداد کندل‌های متناوب به آستانه (`ALTERNATION_THRESHOLD`، پیش‌فرض **۶**)
  برسد، یک پیام در تلگرام ارسال می‌شود. یعنی پس از ۵ کندل متناوب، روی کندل ۶ام
  هشدار می‌آید.
- تا وقتی تناوب نشکند دوباره اسپم نمی‌شود؛ با شکستن الگو، شمارش از نو شروع می‌شود.

## راه‌اندازی

۱. یک ربات در تلگرام بسازید: به [@BotFather](https://t.me/BotFather) پیام دهید،
   دستور `/newbot` را بزنید و توکن را بگیرید.

۲. فایل محیطی را آماده کنید:

```bash
cp .env.example .env
# سپس TELEGRAM_TOKEN را در فایل .env قرار دهید
```

۳. نصب وابستگی‌ها:

```bash
pip install -r requirements.txt
```

۴. اجرا:

```bash
python bot.py
```

۵. در تلگرام به ربات خود `/start` بفرستید. ربات به‌طور خودکار `chat_id` شما را
   ذخیره می‌کند و هشدارها را به همان‌جا می‌فرستد.

## دستورات تلگرام

- `/start` — فعال‌سازی و توضیح کوتاه
- `/status` — نمایش آخرین کندل و طول تناوب فعلی

## تنظیمات (متغیرهای محیطی)

| متغیر | پیش‌فرض | توضیح |
|-------|---------|-------|
| `TELEGRAM_TOKEN` | — | توکن ربات (الزامی) |
| `TELEGRAM_CHAT_ID` | خالی | در صورت خالی بودن با `/start` خودکار پر می‌شود |
| `PRODUCT` | `BTCUSDT` | نماد معاملاتی بایننس |
| `GRANULARITY` | `300` | اندازه کندل به ثانیه (۳۰۰ = ۵ دقیقه) |
| `ALTERNATION_THRESHOLD` | `6` | تعداد کندل متناوب لازم برای هشدار |
| `POLL_SECONDS` | `20` | فاصله بررسی کوین‌بیس |

## اجرای دائمی ۲۴ ساعته

برای اجرای پایدار می‌توانید از `systemd`، `pm2`، `docker` یا یک سرور ابری
استفاده کنید. نمونه ساده با `nohup`:

```bash
nohup python bot.py > bot.log 2>&1 &
```

## منبع داده

داده‌ها از API عمومی بایننس گرفته می‌شوند (بدون نیاز به کلید API):

```
https://data-api.binance.vision/api/v3/klines?symbol=BTCUSDT&interval=5m
```

# 🤖 ربات ترید خودکار پلی‌مارکت (`trade_bot.py`)

علاوه بر ربات هشدار، یک **ربات ترید خودکار** هم وجود دارد که روی بازارهای
سری «BTC Up/Down ۵ دقیقه‌ای» پلی‌مارکت معامله می‌کند: شما استراتژی و
محدودیت‌های پولی را تعیین می‌کنید و ربات بدون دخالت شما ترید می‌کند و
نتیجه هر معامله را در تلگرام گزارش می‌دهد.

## نحوه کار

1. ابتدای هر پنجره ۵ دقیقه‌ای، نتیجه پنجره‌های قبلی (Up/Down) خوانده می‌شود
   و **استراتژی** تصمیم می‌گیرد: خرید Up، خرید Down، یا بدون معامله.
2. **مدیر ریسک** قبل از هر سفارش بررسی می‌کند: قیمت ورود از سقف مجاز بالاتر
   نباشد، سقف ضرر روزانه پر نشده باشد و تعداد باخت‌های پشت سر هم از حد
   نگذشته باشد. اگر هرکدام نقض شود، آن روز دیگر معامله نمی‌کند.
3. سفارش به‌صورت Market (FOK) از طریق API رسمی پلی‌مارکت (CLOB) ثبت می‌شود.
4. بعد از بسته‌شدن پنجره، برد/باخت محاسبه و در تلگرام گزارش می‌شود
   (سود/زیان همان معامله + سود/زیان روز + سود/زیان کل).

## استراتژی‌ها (`strategies.py`)

| نام | منطق | حالت‌ها |
|-----|------|---------|
| `alternation` | وقتی چند پنجره متوالی یک‌درمیان شده‌اند (سبز/قرمز/سبز/...) وارد می‌شود | `follow` = ادامه تناوب، `fade` = شکستن تناوب |
| `streak` | وقتی چند پنجره متوالی هم‌جهت بوده‌اند وارد می‌شود | `follow` = ادامه روند، `fade` = برگشت روند |

استراتژی دلخواه خودتان را هم می‌توانید اضافه کنید: در `strategies.py` از کلاس
`Strategy` ارث‌بری کنید، متد `decide()` را پیاده کنید و در دیکشنری
`STRATEGIES` ثبتش کنید. ورودی `decide` لیست جهت پنجره‌های قبلی است
(`+1` یعنی Up و `-1` یعنی Down) و خروجی `"up"`، `"down"` یا `None`.

## راه‌اندازی — اول حتماً حالت تمرینی!

ربات **به‌طور پیش‌فرض در حالت تمرینی (`DRY_RUN=true`)** است: همه‌چیز واقعی
است (قیمت لحظه‌ای، سیگنال، نتیجه پنجره) ولی هیچ پولی خرج نمی‌شود. چند روز
در این حالت اجرا کنید و گزارش‌های تلگرام را ببینید تا مطمئن شوید استراتژی
ضررده نیست.

```bash
pip install -r requirements.txt
cp .env.example .env   # سپس TELEGRAM_TOKEN و TELEGRAM_CHAT_ID را پر کنید
python trade_bot.py
```

## فعال‌کردن ترید واقعی

1. در پلی‌مارکت حساب بسازید و **USDC روی شبکه Polygon** واریز کنید
   (همان پولی که به ربات می‌دهید؛ هر معامله `STAKE_USDC` از آن خرج می‌کند).
2. کلید خصوصی را از پلی‌مارکت بگیرید: Profile → Settings → Export Private Key.
3. در `.env` این‌ها را تنظیم کنید:

```bash
DRY_RUN=false
POLY_PRIVATE_KEY=0x...        # کلید خصوصی صادرشده از پلی‌مارکت
POLY_FUNDER=0x...             # آدرس واریز (deposit) حساب پلی‌مارکت شما
POLY_SIGNATURE_TYPE=1         # 1 = حساب ایمیلی، 2 = کیف‌پول مرورگر، 0 = EOA مستقیم
```

## تنظیمات ربات ترید

| متغیر | پیش‌فرض | توضیح |
|-------|---------|-------|
| `DRY_RUN` | `true` | `false` = پول واقعی! |
| `STRATEGY` | `alternation` | نام استراتژی |
| `STRATEGY_MODE` | `follow` | `follow` یا `fade` |
| `ALTERNATION_THRESHOLD` | `5` | حداقل طول الگو برای ورود |
| `STAKE_USDC` | `5` | مبلغ هر معامله (USDC) |
| `MAX_ENTRY_PRICE` | `0.60` | سقف قیمت ورود (بالاتر = شانس بدتر) |
| `DAILY_LOSS_LIMIT_USDC` | `20` | سقف ضرر روزانه؛ بعد از آن تا روز بعد متوقف می‌شود |
| `MAX_CONSECUTIVE_LOSSES` | `4` | حداکثر باخت پیاپی؛ بعد از آن تا روز بعد متوقف می‌شود |
| `ENTRY_WINDOW_SECONDS` | `90` | فقط در N ثانیه اول هر پنجره وارد می‌شود |

وضعیت سود/زیان در فایل `trader_state.json` ذخیره می‌شود تا با ری‌استارت،
محدودیت‌های روزانه از بین نروند.

## ⚠️ هشدارهای مهم

- **هیچ استراتژی‌ای سود را تضمین نمی‌کند.** بازارهای ۵ دقیقه‌ای Up/Down
  بسیار شبیه شیر-یا-خط هستند و اسپرد/قیمت ورود به ضرر شماست؛ کاملاً ممکن
  است ربات ضرر بدهد. فقط با پولی شروع کنید که از دست رفتنش برایتان مهم نیست
  و `STAKE_USDC` و `DAILY_LOSS_LIMIT_USDC` را کوچک نگه دارید.
- **کلید خصوصی = کل موجودی.** فایل `.env` را هرگز کامیت یا منتشر نکنید
  (در `.gitignore` هست). ربات را روی سرور شخصی/قابل‌اعتماد اجرا کنید، نه
  روی GitHub Actions عمومی.
- سهم‌های برنده معمولاً خودکار تسویه می‌شوند؛ اگر موجودی‌ای معلق ماند،
  در سایت پلی‌مارکت آن را Redeem کنید.
- استفاده از پلی‌مارکت تابع قوانین کشور شماست؛ مسئولیت رعایت آن با شماست.
