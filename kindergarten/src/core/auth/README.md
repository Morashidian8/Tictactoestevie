# احراز هویت و حساب

بخش ۳.۲ و ۱۴.۴ سند. قدم چهار.

قواعدی که این پوشه نگه می‌دارد:

- ورود با شماره تلفن و کد یکبارمصرف، از راه قلاب پیامک Supabase خودمیزبان.
- یک شماره می‌تواند چند حساب داشته باشد. کلید یکتا `(phone, role, center_id)` است.
- `staff.role` مرجع نقش است. `user_account.role` نسخه بدل با قید یکسان‌بودن.
  برای حساب سرپرست که ردیف `staff` ندارد، `user_account.role` تنها منبع است.
- `user_account.phone` تنها مرجع احراز هویت است. `staff.phone` و `guardian.phone`
  فقط برای تماس‌اند.
- دسترسی‌ها هرگز ترکیب نمی‌شوند. نشست فعال دقیقاً یک `user_account` است.
