# سامانه مدیریت مهدکودک

PWA فارسی و راست‌به‌چپ برای گرداندن کار روزانه مهدکودک ۳ تا ۶ سال.
سند محصول مرجع تمام تصمیم‌هاست.

## پشته

React و TypeScript روی Vite، با Supabase خودمیزبان برای احراز هویت و
پایگاه داده و استوریج. میزبانی داخل کشور، طبق بند ۱۰.۲ سند.

## اجرا

```
npm install
npm run dev
```

بعد صفحه را باز کنید و با یکی از این دو شماره وارد شوید. کد همیشه `11111`
است و روی صفحه هم نوشته شده.

| شماره | چه چیزی را نشان می‌دهد |
|---|---|
| `09120000001` | یک حساب، یک کلاس. ورود مستقیم بدون صفحه انتخاب حساب |
| `09120000002` | دو حساب و دو کلاس. صفحه انتخاب حساب، کلید تعویض کلاس، جابه‌جایی حساب |

این اجرا به سرور نیاز ندارد. لایه داده و احراز هویت دو پیاده‌سازی دارند و
فعلاً نسخه محلی کار می‌کند. صفحه نمی‌داند با کدام‌یک کار می‌کند.

## دستورها

```
npm run dev        اجرای محلی
npm run build      ساخت نسخه تولید
npm run typecheck  بررسی نوع‌ها
npm test           تست‌های واحد
npm run test:db    مهاجرت‌ها و قواعد دیتابیس، روی پستگرس موقت
npm run test:e2e   جریان واقعی در مرورگر (به npm run dev نیاز دارد)
```

## ساختار

مطابق بخش ۱۴.۵ سند، زیر `src/`:

```
src/app/         teacher · parent · manager
src/core/        auth · data · sync · media
src/design-system/
src/reports/
src/i18n/
```

هر پوشه یک README دارد که می‌گوید چه قاعده‌ای را نگه می‌دارد و به کدام بند
سند وصل است.

## قواعد الزام‌آور

- بخش ۱۰ سند و پیوست ج غیرقابل مذاکره‌اند.
- بخش ۱۲ مرجع تمام تصمیمات بصری است. توکنی که در سند نیست، بدون پرسیدن
  ساخته نمی‌شود.
- تاریخ همه‌جا جلالی. هیچ تاریخ میلادی در رابط کاربری دیده نمی‌شود.
- حالت تاریک ساخته نمی‌شود.
- هر پرس‌وجوی داده به `center_id` مقید است، و این قید در `core/data`
  اعمال می‌شود نه در تک‌تک کوئری‌ها.

## چه چیزی ساخته شده

- اسکلت بخش ۱۴.۵ و لایه تاریخ جلالی و ارقام فارسی
- توکن‌ها و اجزای بخش ۱۲ که صفحه «امروز» لازم دارد
- تایپوگرافی فارسی واقعی، آیکون‌های Lucide، و چهره جایگزین عکس
- شِمای M1 تا M7 با سیاست‌های سطر-محور و قواعد سفت در خود دیتابیس
- ورود با شماره و کد یکبارمصرف، چند حساب برای یک شماره، جابه‌جایی حساب
- صفحه «امروز» پنل مربی، با شیت استثناهای ورود
- صفحه «ثبت گروهی»، با استثنای هر کودک و چرخش پیشنهاد یادداشت
- صفحه «بستن روز»، با ارسال و قفل، و ارسال خودکار سمت سرور
- خط پردازش عکس سمت کلاینت، بخش ۱۴.۳

پنل والد و پنل مدیر ساخته نشده‌اند و برای بخش‌های ساخته‌نشده داده‌ای
ساخته نشده.

## در انتظار

- **فونت‌ها.** استعداد و مربع هنوز نرسیده‌اند. فعلاً وزیرمتن نشسته که سند
  خودش جایگزینش نامیده، خودمیزبان و پیش‌ذخیره‌شده برای کارکرد آفلاین.
  با رسیدن فایل‌ها فقط دو اعلان به `fonts.css` اضافه می‌شود؛ هیچ اندازه
  و فاصله‌ای عوض نمی‌شود چون هیچ‌کدام بر اساس جایگزین تنظیم نشده‌اند.
- **آیکون اپ.** `public/icon.svg` موقت است و با نشان واقعی مهد عوض می‌شود.
- **Supabase.** تا برپا شدن سرور، نسخه محلی لایه داده و احراز هویت کار
  می‌کند. مهاجرت‌ها آماده‌اند و روی پستگرس آزمایش شده‌اند.
- **صف آفلاین.** رابطش در `core/sync` هست و همه نوشتن‌ها از آن رد می‌شوند،
  ولی صف ماندگار هنوز پیاده نشده.
- **تگ عکس.** بخش ۵.۵ می‌گوید مربی در پنجره طلایی عکس‌ها را از گالری
  انتخاب و تگ می‌کند. فشرده‌سازی آماده است ولی آپلود به استوریج وصل
  نشده، پس این بخش هنوز نیست.
- **زمان‌بند ارسال خودکار.** تابع `app.auto_send_due_reports` نوشته و
  آزمایش شده، ولی هنوز چیزی دوره‌ای صدایش نمی‌زند. اپ نمی‌تواند این کار
  را بکند، چون بخش ۵.۹ می‌گوید «حتی اگر مربی دکمه را نزند» و گوشی مربی
  ممکن است خاموش باشد.
