# بازبینی طراحی

عکس‌برداری خودکار از همه صفحه‌های ساخته‌شده، برای دادن به طراح.

```
npm run dev -- --port 5199      # در یک ترمینال
node design-review/capture.mjs  # عکس‌ها در shots/
node design-review/build.mjs    # index.html از shots/index.json
```

`capture.mjs` همان جریانی را طی می‌کند که مربی و خانواده طی می‌کنند، پس
عکس‌ها حالت ساختگی نیستند. اگر صفحه‌ای عوض شد، این را دوباره اجرا کنید.

این پوشه بخشی از محصول نیست و در بیلد نمی‌آید.
