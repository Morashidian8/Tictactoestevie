# ربات پیش‌بینی رنگ کندل بیت‌کوین (Next-Candle Color Predictor)

> این یک ربات **جداگانه** از ربات هشدار تناوب (`bot.py`) است. به آن دست نمی‌زند
> و منطق ربات قبلی تغییری نمی‌کند. هر کدام را خواستی جدا اجرا کن.

رباتی تلگرامی که مثل یک **اسکلپر** عمل می‌کند: حدود **۱ دقیقه قبل** از باز شدن
هر کندل **۵ دقیقه‌ای بیت‌کوین** (BTCUSDT از بایننس)، با اجرای یک مجموعه تحلیل
تکنیکال حدس می‌زند آن کندل **سبز 🟢** یا **قرمز 🔴** بسته خواهد شد و فقط
**ساعت کندل + رنگ** را می‌فرستد. مثال پیام:

```
۱۲:۰۵🟢
```

> ⚠️ **توجه صادقانه:** رنگ کندل بعدی عملاً نزدیک به «شیر یا خط» است و هیچ
> تحلیلی نمی‌تواند آن را با قطعیت پیش‌بینی کند. این فقط یک حدس منظم و
> بازتولیدپذیر بر پایه تحلیل تکنیکال است، نه تضمین سود.

## فایل‌ها

- `predict_bot.py` — ربات تلگرام (زمان‌بند + دستورات)
- `predictor.py` — موتور تحلیل (EMA/MACD/RSI/ROC/حجم)

## دستورات تلگرام

| دستور | کار |
|-------|-----|
| `/start` | شروع پیش‌بینی مداوم (۱ دقیقه قبل از هر کندل ۵ دقیقه‌ای) |
| `/stop` | توقف پیش‌بینی |
| `/status` | وضعیت (فعال/متوقف) و جزئیات تحلیل آخرین پیش‌بینی |
| `/predict` | یک پیش‌بینی فوری برای کندل بعدی همین حالا |

پس از `/start` تا وقتی `/stop` بزنی به‌صورت مداوم ۲۴ ساعته کار می‌کند.

## راه‌اندازی

۱. یک ربات **جدید** بساز (توصیه می‌شود از ربات قبلی جدا باشد): به
   [@BotFather](https://t.me/BotFather) پیام بده، `/newbot` بزن و توکن بگیر.

۲. در فایل `.env` توکن را قرار بده (متغیر مخصوص این ربات تا با ربات قبلی قاطی
   نشود):

```bash
PREDICT_TELEGRAM_TOKEN=123456:ABC-your-predictor-token
```

> اگر `PREDICT_TELEGRAM_TOKEN` نگذاری، به‌صورت پیش‌فرض از `TELEGRAM_TOKEN`
> استفاده می‌کند — اما آن وقت روی همان ربات قبلی می‌نشیند، که توصیه نمی‌شود.

۳. نصب وابستگی‌ها و اجرا:

```bash
pip install -r requirements.txt
python predict_bot.py
```

۴. در تلگرام به این ربات `/start` بفرست.

## تنظیمات (متغیرهای محیطی)

همه با پیشوند `PREDICT_` تا هرگز با ربات قبلی تداخل نکنند:

| متغیر | پیش‌فرض | توضیح |
|-------|---------|-------|
| `PREDICT_TELEGRAM_TOKEN` | — | توکن این ربات (یا fallback به `TELEGRAM_TOKEN`) |
| `PREDICT_TELEGRAM_CHAT_ID` | خالی | با `/start` خودکار پر می‌شود |
| `PREDICT_PRODUCT` | `BTCUSDT` | نماد بایننس |
| `PREDICT_INTERVAL` | `5m` | تایم‌فریم کندل |
| `PREDICT_GRANULARITY` | `300` | اندازه کندل به ثانیه |
| `PREDICT_KLINES_LIMIT` | `200` | تعداد کندل برای اندیکاتورها |
| `PREDICT_LEAD_SECONDS` | `60` | چند ثانیه قبل از باز شدن کندل پیش‌بینی برود |
| `PREDICT_TICK_SECONDS` | `3` | فاصله بررسی ساعت |
| `PREDICT_DISPLAY_TZ` | `Asia/Tehran` | منطقه زمانی ساعت پیام |
| `PREDICT_PERSIAN_DIGITS` | `1` | `1` = ارقام فارسی، `0` = لاتین |

## اجرای دائمی

```bash
nohup python predict_bot.py > predict_bot.log 2>&1 &
```

دو ربات می‌توانند هم‌زمان کنار هم اجرا شوند (هر کدام با توکن خودش).
