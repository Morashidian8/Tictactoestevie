# ردیاب کیف پول پلی‌مارکت (Polymarket Wallet Tracker)

یک ابزار **کاملاً مستقل**: آدرس هر کیف پولی را بده و یک بازه زمانی دلخواه انتخاب کن
(مثلاً «یک ساعت اخیر» یا «دو ساعت اخیر»)، تا

- **موجودی نقدی USDC** آن کیف پول روی شبکه‌ی Polygon، و
- **سود/زیانِ تحقق‌یافته‌ی معاملاتش در پلی‌مارکت** در همان بازه

را دقیق محاسبه و نمایش دهد.

این پروژه هیچ وابستگی‌ای به بقیه‌ی کدهای این مخزن (مثل `polybot`) ندارد:
پوشه‌ی جدا، `requirements.txt` مستقل، و بدون هیچ import مشترک.

---

## 🚀 بدون سرور (روش اصلی)

**نیازی به سرور نداری.** کل محاسبات داخل خودِ مرورگر اجرا می‌شود (وب‌اپ مستقیم به
API پلی‌مارکت و شبکه‌ی Polygon وصل می‌شود)، پس به‌صورت فایل‌های ثابت روی
**GitHub Pages رایگان** منتشر می‌شود.

این مخزن از قبل روی GitHub Pages منتشر می‌شود؛ بعد از merge شدن این تغییرات به
شاخه‌ی `main`، اپ به‌صورت خودکار اینجا در دسترس خواهد بود:

```
https://morashidian8.github.io/Tictactoestevie/wallet/
```

کافی است آن لینک را روی گوشی یا کامپیوتر باز کنی، آدرس کیف پول و بازه‌ی زمانی را
بدهی. می‌توانی از منوی مرورگر «Add to Home Screen» بزنی تا مثل یک اپ نصب شود.

> هیچ داده‌ای روی سروری ذخیره نمی‌شود؛ آدرس فقط در حافظه‌ی محلی مرورگر خودت می‌ماند.

### تست محلی بدون هیچ نصبی

```bash
# هر سرور ثابت ساده‌ای کافی است، فقط برای باز شدن فایل‌ها در مرورگر:
python -m http.server -d wallet_tracker/webui 8080
# مرورگر: http://127.0.0.1:8080
```

اگر ترجیح می‌دهی محاسبات سمت سرور انجام شود (مثلاً برای دور زدن محدودیت CORS یا

## چطور کار می‌کند؟

| بخش | منبع داده |
| --- | --- |
| موجودی USDC | فراخوانی فقط‌خواندنیِ `balanceOf` روی توکن‌های USDC.e و USDC روی Polygon (JSON-RPC) |
| ارزش پورتفولیو و پوزیشن‌های باز | Polymarket Data API (`/value`، `/positions`) |
| سود/زیان معاملات | Polymarket Data API (`/activity`) + موتور FIFO محلی |

### چرا سود/زیان «دقیق» است؟

«چقدر در یک ساعت اخیر سود کرد» یک سؤال درباره‌ی سود **تحقق‌یافته** است:

> سود تحقق‌یافته = عایدیِ چیزی که بسته‌ای − بهای تمام‌شده‌ی همان سهم‌ها

بهای تمام‌شده ممکن است مربوط به خریدی چند روز قبل باشد، پس موتور (`pnl.py`) **کل
تاریخچه‌ی فعالیت** کیف پول را به‌ترتیب زمان بازپخش می‌کند، موجودیِ هر پیامد (outcome)
را به‌صورت لات‌های **FIFO** نگه می‌دارد، و فقط بعد از آن رویدادهای بسته‌شدن را با
بازه‌ی زمانی برش می‌زند. انواع رویداد پشتیبانی‌شده: `BUY`, `SELL`, `REDEEM`, `MERGE`,
`SPLIT`, `REWARD`.

> سود/زیانِ **تحقق‌نیافته‌ی** پوزیشن‌های باز هم نشان داده می‌شود، اما جداگانه و با برچسبِ
> «در لحظه» — چون به بازه‌ی زمانی محدود نیست.

## اجرا

```bash
pip install -r wallet_tracker/requirements.txt

# وب‌اپ (PWA) + API
uvicorn wallet_tracker.server:app --host 0.0.0.0 --port 8000
# مرورگر: http://127.0.0.1:8000
```

> ⚠️ هاست‌های پلی‌مارکت و Polygon باید از جایی که سرور اجرا می‌شود قابل دسترسی باشند.
> (سندباکس توسعه‌ی ابری این هاست‌ها را می‌بندد؛ روی سرور/کامپیوتر خودت اجرا کن.)

### خط فرمان (بدون مرورگر)

```bash
python -m wallet_tracker.cli 0xWALLET --minutes 120
python -m wallet_tracker.cli 0xWALLET --preset 2h --json
```

### API

```
GET /api/report?address=0x...&minutes=120
GET /api/report?address=0x...&preset=2h      # 1h,2h,6h,12h,24h,7d
```

نمونه‌ی خروجی (خلاصه):

```json
{
  "address": "0x...",
  "window": { "minutes": 120, "label": "۲ ساعت اخیر" },
  "balance": { "usdc_e": 123.45, "usdc_native": 0.0, "total_cash": 123.45 },
  "portfolio_value": 250.0,
  "pnl_window": { "realized": 20.0, "rewards": 0.0, "total": 20.0,
                  "net_cash_flow": 60.0, "trades_count": 1, "events": [ ... ] },
  "open_positions": { "unrealized_pnl_now": 1.0, "count": 1, "positions": [ ... ] },
  "warnings": []
}
```

## ساختار

```
wallet_tracker/
├── polymarket_client.py   # خواندن Data API پلی‌مارکت (صفحه‌بندی، parse دفاعی)
├── chain.py               # موجودی USDC روی Polygon (eth_call/balanceOf)
├── pnl.py                 # موتور سود/زیان FIFO (خالص، تست‌شده)
├── report.py              # چسباندن همه به هم → گزارش JSON
├── server.py              # FastAPI: سرو PWA + /api/report
├── cli.py                 # نسخه‌ی خط فرمان
├── webui/                 # وب‌اپ (PWA): index.html, app.js, styles.css, sw.js
└── tests/                 # تست‌های آفلاین
```
