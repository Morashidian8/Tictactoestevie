عکس حواله را بده، فایل اکسل بگیر. همه‌چیز روی همین گوشی.

کلید رایگان از aistudio.google.com/apikey → «Create API key». روی همین گوشی ذخیره می‌شود.

دقت بالاتر روی دست‌خط. از console.anthropic.com. با اعتبار خودت مصرف می‌شود. روی همین گوشی ذخیره می‌شود.

جنسیت از روی نام حدس زده می‌شود؛ سایزِ ننوشته به‌صورت چرخشی پر می‌شود. قبل از استفاده یک مرور کوتاه بکن.
