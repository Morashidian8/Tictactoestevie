# اپ استخراج حواله تجهیزات حفاظت فردی → اکسل

از روی عکسِ «حواله صدور کالا / MATERIAL ISSUE VOUCHER» مشخصات پرسنل و اقلام را
می‌خواند و فایل اکسل استاندارد ۱۷ ستونه (جدول پرسنل) را می‌سازد.

## چطور کار می‌کند

1. عکس حواله(ها) را می‌گیرد و با هوش مصنوعی (Claude Vision، مدل `claude-opus-4-8`)
   متن دست‌نویس و چاپی را می‌خواند.
2. منطق تجاری را اعمال می‌کند:
   - **جنسیت** از روی نام کوچک تشخیص داده می‌شود.
   - **کد ۱۰ رقمی → کد ملی → نوع قرارداد پیمانکاری**؛ **کد ۵ تا ۷ رقمی → کد پرسنلی → رسمی**.
   - **منطقه** از «واحد متقاضی/شرح کار» چاپی.
   - **عنوان شغل** از دست‌نویسِ جلوی اسم؛ اگر نبود، از جمله‌ی «پرسنل رسمی» → «کارمند رسمی».
   - **عنوان لوازم** از شرح کالا/کد MESC.
   - **تاریخ تحویل** از دست‌نویس کنار امضا (ماه و سال).
   - **سایز**: اگر برای نفر مشخص نشده باشد، از مخزن سایز به‌صورت چرخشی تخصیص می‌یابد تا فایل کامل شود.
3. هر «نفر × هر قلم» یک ردیف در اکسل می‌شود.

اگر **لیست اسامی جدا** از حواله‌ی تجهیزات بدهید، اپ اسامی را به اقلامِ حواله تخصیص می‌دهد.

## اجرا (با کلید رایگان Google Gemini)

۱) یک کلید **رایگان** بگیرید: به <https://aistudio.google.com/apikey> بروید و «Create API key» بزنید.

۲) اپ را اجرا کنید:

```bash
pip install -r ppe_ocr/requirements.txt
export GOOGLE_API_KEY=کلید_رایگان_شما
streamlit run ppe_ocr/app.py
```

سپس در مرورگر: عکس‌ها را آپلود کنید و دکمه‌ی «استخراج و ساخت اکسل» را بزنید.

### موتور استخراج (Gemini پیش‌فرض)

- پیش‌فرض **Google Gemini** است (رایگان). مدل پیش‌فرض `gemini-2.5-flash`؛ با `PPE_GEMINI_MODEL` قابل تغییر.
- اگر خواستید از Anthropic استفاده کنید: `export PPE_PROVIDER=anthropic` و `export ANTHROPIC_API_KEY=...`.

## تست منطق (بدون نیاز به API)

```bash
python -m ppe_ocr.test_logic
```

## پیکربندی (بدون دست‌زدن به کد)

همه‌ی داده‌های قابل‌تنظیم در پوشه‌ی `data/` هستند:

| فایل | کاربرد |
|---|---|
| `mesc_items.json` | نگاشت کد کالا (MESC) → عنوان لوازم/واحد. کد جدید را همینجا اضافه کنید. |
| `size_pools.json` | مخزن سایز برای اقلام بدون سایزِ نفری (البسه حرفی، کفش عددی). |
| `names_gender.json` | دیکشنری نام کوچک → جنسیت (زن/مرد/مبهم). |
| `constants.json` | مقادیر ثابت (نام شرکت، شماره پیمان پیش‌فرض) و هدر ستون‌ها. |

## نکات دقت

- کیفیت عکس مهم‌ترین عامل است: **صاف، روشن، بدون کجی**. عکس چرخیده/محو دقت را پایین می‌آورد.
- جنسیتِ اسم‌های مبهم با «نامشخص(بررسی شود)» علامت می‌خورد.
- قبل از استفاده‌ی نهایی، یک مرور کوتاه روی خروجی توصیه می‌شود.

## ساختار

```
ppe_ocr/
  app.py          رابط کاربری استریم‌لیت (فارسی)
  extractor.py    خواندن عکس با Claude Vision (خروجی ساختاریافته)
  logic.py        منطق قطعی تبدیل به ردیف‌های اکسل
  excel_writer.py نوشتن اکسل ۱۷ ستونه
  config.py       بارگذاری داده‌های data/
  test_logic.py   تست آفلاین منطق
  data/           فایل‌های JSON قابل‌ویرایش
```
