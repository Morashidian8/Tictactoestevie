# FacilityOS — پلتفرم سازمانی مدیریت ساختمان، تأسیسات و نگهداری و تعمیرات (CMMS + CAFM)

> اپلیکیشن اندرویدی سازمانی و **آفلاین‌محور** برای مدیریت ساختمان‌ها، تأسیسات، تجهیزات،
> بازرسی‌ها، چک‌لیست‌ها، نگهداری پیشگیرانه (PM) و اصلاحی (CM)، ایمنی (HSE)، اعلام و اطفاء حریق
> و مستغلات.
>
> فاز اول: **۸۵ ساختمان** — قابل توسعه تا **هزاران ساختمان** و **صدها هزار تجهیز**.

این پوشه، **بستهٔ کامل طراحی و معماری** است (قابل مقایسه با IBM Maximo، Archibus و FM:Systems،
اما ساده و کاربردی برای تکنسین‌های میدانی روی اندروید). اسناد فنی به انگلیسی نوشته شده‌اند
(استاندارد مهندسی)؛ این صفحه نقشهٔ راهنمای فارسی است.

## ماژول‌های کارکردی

```
FacilityOS
├── مدیریت ساختمان‌ها        (اطلاعات پایه، مدارک، فایل‌ها، GPS)
├── نقشهٔ هوشمند            (خوشه‌بندی، مسیریابی، ردیابی تکنسین)
├── ساختار درختی ساختمان    (سلسله‌مراتب طبقه → اتاق → تجهیز)
├── مدیریت تجهیزات          (دسته‌بندی پویا، عمر تجهیز، QR)
├── موتور چک‌لیست/بازرسی    (آیتم پویا، مقدار عددی، شواهد)
├── نگهداری پیشگیرانه (PM)   (زمان‌بندی خودکار، دستور کار)
├── تعمیرات اصلاحی (CM)      (ثبت خرابی، ارجاع، پیگیری)
├── مدیریت دستور کار
├── انبار و قطعات یدکی
├── مدیریت پیمانکاران
├── ماژول HSE              (حوادث، علت‌یابی، اقدامات اصلاحی/پیشگیرانه)
├── اعلام و اطفاء حریق
├── مدیریت انرژی/مصارف
├── مدیریت اسناد (DMS)       (نسخه‌بندی، گردش تأیید، انقضا)
├── تحلیل بحرانیت تجهیزات
├── داشبوردها              (تکنسین → سرپرست → مدیر → مدیرعامل)
├── مرکز پایش ساختمان‌ها     (وضعیت زندهٔ زیرسیستم‌ها)
├── گزارش‌گیری             (PDF/Excel)
├── اعلان‌ها
└── مدیریت کاربران / RBAC / لاگ ممیزی
```

## اصول طراحی

1. **آفلاین‌محور:** همهٔ عملیات بدون اینترنت کار می‌کند؛ همگام‌سازی بعداً انجام می‌شود.
2. **داده‌محور (Metadata-driven):** دسته‌بندی تجهیزات، فیلدهای سفارشی و قالب‌های چک‌لیست
   «داده» هستند، نه کد — افزودن نوع تجهیز یا فرم بازرسی جدید بدون به‌روزرسانی اپ.
3. **چندمستأجری (Multi-tenant):** هر رکورد به `org_id` محدود است.
4. **سریع برای میدان:** اسکن QR تا صفحهٔ تجهیز در ≤ ۲ لمس.
5. **قابل ممیزی:** هر تغییر یک رکورد لاگ تغییرناپذیر می‌سازد.
6. **مقیاس از طریق پارتیشن‌بندی، نه بازنویسی.**

برای شروع، سند [معماری سامانه](docs/01-system-architecture.md) را ببینید.
