# Context: FacilityOS (CMMS + CAFM platform)

Domain language (ubiquitous vocabulary) for the enterprise facility-management platform.

## Core entities

- **Org / Tenant** — top-level customer boundary. Everything is scoped to an `org_id`.
- **Building** — a physical structure managed by the org. Has a code, address, GPS, documents,
  and a location tree.
- **Location node** — a node in the **Digital Building Twin** hierarchy
  (Building → Floor → Room/Zone → sub-zone). Self-referencing tree. Assets hang off location nodes.
- **Asset** — a maintainable piece of equipment (elevator, chiller, fire pump…). Belongs to one
  **Asset Category** and one location node. Has lifecycle dates, a QR code, media, and history.
- **Asset Category** — metadata-defined classification (e.g. *Vertical Transportation*). Owns a
  set of **custom field definitions** so new asset types need no code change.
- **Custom Field Definition** — a typed attribute (text/number/date/enum/bool) attached to a
  category or template. Drives dynamic forms.

## Work & maintenance

- **Checklist Template** — a reusable inspection form: ordered **checklist items**, each with a
  response type (pass/fail/NA, numeric, text, photo, signature…).
- **Inspection** — an executed instance of a checklist template against an asset/building, with
  recorded item responses and evidence.
- **PM (Preventive Maintenance) Plan** — a schedule (calendar- or meter-based) that auto-generates
  **work orders**.
- **CM (Corrective Maintenance)** — reactive work triggered by a **Fault**.
- **Fault** — a reported defect on an asset. Has priority and a status lifecycle.
- **Work Order (WO)** — the unit of dispatched work. Has a number, assignee, due date, parts,
  labor, evidence. Generated by PM, CM, inspection failures, or manually.
- **Criticality** — Critical/High/Medium/Low rating derived from safety/operational/financial
  impact and failure frequency; drives prioritization.

## Inventory & people

- **Spare Part** — a stocked item with min/reorder levels, compatible with assets.
- **Stock Transaction** — issue/return/transfer/count movement against a warehouse.
- **Contractor** — external service provider with contracts, certs, insurance, ratings.
- **User** — an account with one or more **Roles** (Administrator, Supervisor, Manager,
  Technician, Viewer). RBAC governs every action.

## Safety & compliance

- **HSE Incident** — near miss / unsafe act / unsafe condition / accident / property damage.
- **RCA** — Root Cause Analysis. **CAPA** — Corrective And Preventive Actions.
- **Compliance item** — a fire/safety device with inspection + expiry dates and a status.

## Operations

- **Utility Reading** — metered electricity/water/gas/diesel consumption.
- **Document** — versioned file (manual, drawing, contract, certificate) with approval + expiry.
- **Audit Event** — immutable record of who-did-what-when.
- **Sync Operation** — a queued offline mutation awaiting server reconciliation.

## Status vocabularies

- **Fault status:** Open → Assigned → In Progress → Waiting Spare Parts → Completed → Closed.
- **Work order status:** Draft → Scheduled → Assigned → In Progress → On Hold → Completed → Closed → Cancelled.
- **Building health light:** 🟢 OK · 🟡 Attention · 🔴 Critical (computed per subsystem).

## Key metrics

- **MTBF** — Mean Time Between Failures. **MTTR** — Mean Time To Repair.
- **PM Compliance %** — PM work orders completed on time ÷ scheduled.
- **Asset Availability %** — uptime ÷ scheduled time.
- **Asset Health Score** — composite 0–100 from age, failures, overdue PM, criticality.
- **Deferred Maintenance Cost** — estimated cost of postponed work.
