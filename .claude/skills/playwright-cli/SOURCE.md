# منبع

از مخزنِ رسمیِ مایکروسافت [microsoft/playwright-cli](https://github.com/microsoft/playwright-cli) (`skills/playwright-cli`، کامیتِ `c2d8d19`؛ مجوزِ Apache-2.0، فایلِ LICENSE). متن و راهنماهای `references/` بدونِ تغییرند؛ فقط بخشِ «Local notes» (مرورگرِ ازپیش‌نصب‌شده، نصبِ ابزارِ CLI، نکته‌های فارسی) افزوده شده.

توجّه: سرِ این اسکیل `allowed-tools` دارد؛ یعنی وقتی اسکیل فعال است، فرمان‌های `playwright-cli` و `npx playwright` بدونِ پرسیدنِ اجازه اجرا می‌شوند.
