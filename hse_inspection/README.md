# اپلیکیشن بازدید ایمنی و آتش‌نشانی ساختمان (HSE Inspection)

اپلیکیشن تحت‌وب برای بازدید ایمنی ساختمان توسط ناظر HSE، بر اساس چک‌لیست اکسل
(۱۸۹ آیتم در ۱۸ حوزه).

## امکانات
1. **ویزارد تک‌آیتمی** — هر بار فقط یک ردیف نمایش داده می‌شود. ناظر وضعیت را انتخاب می‌کند
   (✅ مطلوب / ⚠️ نیاز به بهبود / ❌ نامطلوب / **N/A کاربرد ندارد**)، در صورت نیاز توضیح می‌نویسد
   و عکس آپلود می‌کند، سپس «بعدی» را می‌زند و ردیف بعد جایگزین می‌شود.
2. **ناوبری ویزاردی** — قبلی/بعدی، نوار پیشرفت، ذخیره خودکار پیشرفت در مرورگر و سرور
   (امکان ادامه بازدید قبلی).
3. **خروجی Word (گزارش تصویری)** — عکس‌های آپلودشده با ذکر آیتم و توضیح ناظر زیر هر عکس،
   فقط برای موارد دارای ایراد (نامطلوب / نیاز به بهبود) یا دارای عکس و توضیح. راست‌چین فارسی.
4. **خروجی Excel** — فقط ردیف‌های پاسخ‌داده‌شده، با **حذف موارد «کاربرد ندارد»**،
   شامل وضعیت، توضیح، اولویت، امتیاز، تعداد عکس و محاسبه درصد ایمنی.

## اجرا

```bash
cd hse_inspection
python3 -m venv venv && source venv/bin/activate   # اختیاری
pip install -r requirements.txt
python app.py
```

سپس مرورگر را روی `http://localhost:5000` باز کنید (روی موبایل با IP سیستم).

## ساختار
- `app.py` — بک‌اند Flask و تولید خروجی‌های Word/Excel
- `checklist_data.json` — داده استخراج‌شده از فایل اکسل اصلی
- `templates/index.html` — صفحه ویزارد
- `static/style.css` , `static/app.js` — رابط کاربری راست‌چین
- `uploads/` — عکس‌های آپلودشده (در گیت نادیده گرفته می‌شود)
