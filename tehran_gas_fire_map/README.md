# نقشه ادارات گاز شهر تهران و نزدیک‌ترین ایستگاه آتش‌نشانی

نقشه تعاملی (Leaflet/folium، فارسی) که برای هر ساختمان شرکت گاز استان تهران **داخل شهر تهران**:

- محل اداره گاز را نشان می‌دهد (نشانگر نارنجی 🔥)
- نزدیک‌ترین ایستگاه آتش‌نشانی را بر اساس **زمان واقعی رانندگی** پیدا می‌کند (نشانگر قرمز 🚒)
- مسیر رانندگی خودروی آتش‌نشانی را روی نقشه می‌کشد (خط قرمز)
- نام ایستگاه، مسافت (کیلومتر) و زمان تقریبی رسیدن (دقیقه) را در پاپ‌آپ نمایش می‌دهد

## فایل‌ها

| فایل | نقش |
| ---- | --- |
| `data/gas_offices.json` | ۲۸ ساختمان داخل شهر تهران (از جدول ۱۴۰۵ شرکت گاز) + فهرست موارد خارج از شهر که حذف شدند |
| `scripts/fetch_geo.py` | در GitHub Actions اجرا می‌شود: ایستگاه‌ها از Overpass/OSM، اصلاح مختصات از Nominatim، مسیر/زمان از OSRM → خروجی `data/geo_results.json` |
| `.github/workflows/tehran-geo.yml` | ورک‌فلوی واکشی داده (push روی این شاخه یا اجرای دستی) |
| `scripts/build_map.py` | ساخت نقشه HTML از نتایج → `output/tehran_gas_fire_map.html` |

## اجرا

```bash
pip install folium
python tehran_gas_fire_map/scripts/build_map.py
# خروجی: tehran_gas_fire_map/output/tehran_gas_fire_map.html — در مرورگر باز کنید
```

## نکات دقت

- مختصات ادارات از روی آدرس متنی برآورد و با Nominatim اصلاح شده؛ خطای چند صد متری ممکن است.
- زمان‌های OSRM **بدون ترافیک** است؛ زمان واقعی اعزام به ترافیک لحظه‌ای بستگی دارد. شماره فوریت آتش‌نشانی: **۱۲۵**.
- داده ایستگاه‌ها از OpenStreetMap است (© OpenStreetMap contributors, ODbL) و ممکن است کامل نباشد.
